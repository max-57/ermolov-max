// PRODUCT DESIGN • ENTERPRISE B2B SaaS

Оптимизация строительного процесса

Автоматизированная B2B-платформа для управления строительным снабжением, превращающая хаотичный процесс закупок в прозрачную цифровую систему, которая исключает рутинный перенос данных и минимизирует потери информации.

// ЗАДАЧА

Хаос в закупках: ручной перенос данных из Excel, долгая переписка по email, потери данных и отсутствие контроля.

// РЕШЕНИЕ

Спроектировал B2B-систему: автоматизировал цикл от заявки до заказа, внедрил «бесшовную» связь с почтой и систему трекинга статусов.

// РЕЗУЛЬТАТ

Прозрачный процесс закупок, ускоренная обработка заявок, минимизация рутины.

Фокус и экспертиза

// ДО // ПОСЛЕ

Описание работы

Моя работа как Product Designer'а заключалась в том, чтобы убрать «когнитивный шум» при работе со сложными данными. Снабженцы работали на пределе внимания, переключаясь между десятками окон.
Я внедрил принцип контекстного управления: пользователь не должен уходить с экрана, чтобы совершить действие. Все инструменты (статусы, отправка запросов, комментарии) теперь находятся в поле зрения или вызываются кликом по строке.

Функциональные решения (UX-фокус)

В проекте я сфокусировался на трех ключевых механиках:
Массовые действия:

1. Реализовал режим выбора нескольких позиций в таблице. Теперь снабженец меняет статус 50 позиций в один клик.

2. Умная таблица: Спроектировал интерактивные заголовки и группировки, позволяющие управлять сметами любой сложности без потери контекста.

3. Витрина для внешнего пользователя: Разработал упрощенный интерфейс для поставщиков, который работает без регистрации, что увеличило скорость ответов на заявки.
