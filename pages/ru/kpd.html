// ЗАДАЧА

Снизить операционное трение в семье, систематизировать задачи и повысить вовлеченность детей через геймификацию.

// РЕШЕНИЕ

Создана единая платформа с разграничением ролей (Родитель, Ребенок, Родственник) и нативным онбордингом.

// РЕЗУЛЬТАТ

Прозрачный контур коммуникации, автоматизация мотивационных цепочек и сокращение времени на адаптацию новых пользователей.

Экспертиза

Product Design Gamification UX Strategy Onboarding

Главная: Центр управления

Главная спроектирована как точка быстрого доступа. Для родителя — это фокус на статусах задач детей и текущих достижениях, для ребенка — визуализация личного прогресса и «наградного фонда».

// ГЛАВНЫЙ ЭКРАН: РОДИТЕЛЬ • РЕБЕНОК • РОДСТВЕННИК

Цели и геймификация

Механика задач переведена в игровой формат. Вместо списка дел — система «цель — достижение — награда». Это формирует петлю привычки (habit loop) и позволяет ребенку самостоятельно управлять своей мотивацией.

// УПРАВЛЕНИЕ ЦЕЛЯМИ: РОДИТЕЛЬ • РЕБЕНОК • РОДСТВЕННИК

Семейная экосистема

Реализовал 3 роли: Родитель (администрирование), Ребенок (выполнение), Родственник (поддержка). Контекст пользователя меняется динамически, обеспечивая приватность данных и релевантный контент для каждого участника.

// РОЛЕВАЯ МОДЕЛЬ: РОДИТЕЛЬ • РЕБЕНОК • РОДСТВЕННИК

Обучение и онбординг

Контекстный онбординг, который объясняет ценность фич в процессе их использования. Я спроектировал флоу так, чтобы пользователь не «учился», а совершал первое целевое действие, получая быстрый результат.
