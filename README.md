# Портфолио Максима Ермолова

Статический сайт на Nuxt 4. Нужен Node.js 22.12+.

```sh
npm ci
npm run dev
npm run typecheck
npm run generate
```

Сборка сайта находится в `.output/public`. На продакшене базовый путь — `/`, поскольку сайт работает на собственном домене.

## Контент

- `app/content/profile.ts` — профиль, контакты, опыт и образование на русском и английском.
- `app/content/projects.ts` — кейсы. У каждого постоянный `slug`, общие пути к медиа и раздельные поля `ru` и `en`.
- `app/components/ProjectPage.vue` — общий шаблон кейса. Заголовок, описание, детали, секции и медиа берутся из данных проекта.

Русские страницы доступны в корне, английские — под `/en`. Переключатель переводит на тот же кейс. Старые ссылки вроде `/#lesson-space` после загрузки переходят на его обычный URL. Старые адреса `/about-me`, `/logistics` и `/quest-saas` открывают соответствующие страницы.

## GitHub Pages

Workflow **Build Nuxt portfolio** проверяет типы и генерирует статический сайт. Чтобы переключить публикацию на Nuxt, в **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions** и вручную запустите workflow на ветке `main`. Он опубликует `.output/public` на текущем пользовательском домене.

Старые статические файлы пока оставлены в корне, чтобы действующий сайт из ветки продолжал открываться до переключения источника. Nuxt использует `app/`, общие стили `Style.css` и существующие медиа из `images/`. После проверки первой публикации старые HTML и JS можно убрать отдельным коммитом.
